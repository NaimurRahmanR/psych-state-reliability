# Contribution and overlap audit

Date: 2026-09-20. Read with `literature_review.md`; source links there identify verified records. This is a prospective contribution audit, not a priority claim.

| Prior work | Already established or investigated | Proposed empirical question here |
|---|---|---|
| Gross; Uusberg and colleagues | Emotion-regulation processes and appraisal-change mechanisms | Whether a computational state error changes a constrained subsequent intervention |
| Agarwal & Sirts; Ruder et al. | Appraisal modelling and automated appraisal annotation | Persistence and downstream consequences of errors across repeated observations |
| PATIENT-Ψ | Cognitive-model-conditioned simulation | Latent-first non-clinical controlled trajectories with known revision events |
| ESC-Eval; ESC-Judge; CounselBench | Multi-turn support evaluation, expert comparison, evaluator weaknesses | Sensitivity to fluent, state-induced failures and disagreement on those cases |
| TherapyGym; Aghakhani et al. | Automated fidelity/strategy evaluation, clinically informed rubrics | Isolating a single state proposition's contribution using matched repair |
| MemoryBank; LongMemEval | Longitudinal memory, updating, temporal reasoning, abstention | Connecting state errors to specific emotion-regulation decisions |
| PsychoLexTherapy | Structured reasoning and therapeutic memory | Exact overlap with controlled error-persistence experiments remains uncertain pending full text |
| Jewell et al. (2026) | Explicitly therapeutically informed memory framework | Empirical fault-injection/repair overlap remains uncertain pending full text |

The proposed contribution is the **combination** of a tightly bounded psychological ontology, paired common evidence, controlled state faults, measurable error exposure, single-slot repair contrasts, and coverage-aware intervention evaluation. None of these ingredients alone is claimed as new. A literature gap is a working assessment, not evidence of absence.

The primary B–C contrast uses identical extraction proposals and generation settings. A history-only baseline measures overall decision/state-target behaviour, but does not possess a comparable persistent-state intervention point. Its SEPR is therefore not pooled with B/C: forcing a structured probe into A's generator would change A. Fault injection estimates susceptibility given a known fault, **not** the frequency of naturally occurring errors. This restriction is central to the contribution's credibility.

Before a preprint: obtain the two missing full texts, refresh this search, independently review the dataset and rubric, execute real models, obtain actual blinded human annotations, assess uncertainty and ablations, and retain null results. The current package cannot support a results paper or any superiority claim.
