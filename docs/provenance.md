# Provenance of this package

Authoritative base: `psych-state-reliability-research-package.zip` supplied with the task (62 files; SHA-256 `fe255b7501c56ab5eeba2a27284979be3f06115b5838cc33560a4bded60cdffe`; CRC-verified on extraction).

1. **Discarded tree.** An early working copy contained `src/psyr/benchmark/families.py` (using identifiers such as `FAMILY_KEYS`, `family_pool`, `CALIBRATION_FAMILIES`), `src/psyr/benchmark/audit.py`, and a 16,792-byte `dataset.py`. None is in the authoritative ZIP and none was written in this work. The tree was deleted and rebuilt from the ZIP. None of those identifiers appears in this package.
2. **Stray copies.** A copy of the upload ZIP and its extraction later appeared in the workspace. Both were verified SHA-256-identical to the upload and removed.
3. **Every file in this package** is either unchanged from the authoritative ZIP, a V2 edit listed in `V2_CHANGELOG.md`, or an output regenerated by a documented command. `PROVENANCE_DIFF.json` at the package root lists added, removed and modified paths relative to the authoritative ZIP, generated at packaging.
4. **Third-party text.** `docs/evidence/*.md` are copies of Qwen3 and vLLM documentation retrieved from `raw.githubusercontent.com` (hashes in `docs/evidence/SHA256SUMS`); they retain their original licences.
5. **Generated data.** `data/calibration/{latent,manifest,examples}.jsonl` are produced by `python scripts/psyr.py dataset --split calibration`; tests assert they equal fresh regeneration. No model generated any benchmark text.
