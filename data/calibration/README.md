# Calibration data (benchmark V2)

Generated by `python scripts/psyr.py dataset --split calibration` (refuses to overwrite). Tests assert all three files equal fresh regeneration.

| File | Content |
|---|---|
| `latent.jsonl` | 20 latent specifications (CAL-001…020), seed 18471, 12 families, 8 archetypes. SHA-256 of the canonical row list: `7d86ecbb3e34b07bb0391e144f6d7773169f418701a6ae7fbecf7b31cff2c4a3` |
| `manifest.jsonl` | One row per trajectory: family, relationship, ambiguity source, archetype, seed, version, wording variant, latent variables, transition types, superseded propositions, intervention family, applicable degradations, full condition design, latent digest |
| `examples.jsonl` | The 110 primary condition variants rendered, **with evaluation-only gold, observable fields and faults**. For human inspection only; never pass to a live architecture. Only `evidence()` produces model-visible text |

All text was authored from latent states. No model-generated conversation, patient record or real help-seeking text is included. These are calibration/development data and must never be reported as held-out evidence.
